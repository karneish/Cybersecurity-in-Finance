# Glossary

| Term | Meaning |
|---|---|
| **EAL** | Expected Annual Loss — monetary figure for how bad an asset's compromise would be per year (₹) |
| **Risk score** | 0–100 per-asset score combining probability, impact, and exposure |
| **Criticality** | 0–100 asset score from business value, exposure, sensitivity, critical-infra flag |
| **CVSS** | Common Vulnerability Scoring System — industry severity 0–10 |
| **CWE** | Common Weakness Enumeration — weakness classification |
| **SRI** | Sovereign Risk Index — normalised national risk composite |
| **ROSI** | Return On Security Investment — EAL reduction per rupee spent |
| **SLA** | Service Level Agreement |
| **TPRM** | Third-Party Risk Management — vendor exposure and cascade tracking |
| **RAG** | Retrieval-Augmented Generation — answering with retrieved clauses as context |
| **STOMP** | Simple Text Oriented Messaging Protocol — used over WebSocket for live push |
| **JWT** | JSON Web Token — signed access credential (`Authorization: Bearer`) |
| **OR-Tools** | Google's open-source optimisation suite (knapsack / allocation) |
| **XGBoost** | Gradient-boosted decision-tree library for the ML forecast |
| **VaR** | Value at Risk — worst-case loss at a confidence percentile (p95) |
| **pgvector** | PostgreSQL extension for vector similarity (RAG) |
| **Mock LLM** | Deterministic offline "language model" mode used in the AI service |
