# ────────────────────────────────────────────────────────────────────────────
# CyberRisk Quantifier — unified backend dependency set.
#
# The whole backend (api-gateway + 9 microservices) deploys as ONE Render web
# service running ten uvicorn processes, so this file is the union of every
# services/*/pyproject.toml runtime dependency plus the process supervisor.
#
# Web-core versions are PINNED exactly: fastapi/pydantic/starlette have a
# history of breaking changes, and a silent minor bump there breaks the
# gateway's proxy routes or the /ws handshake. Numeric/ML packages use ranges
# because they ship frequent wheel-only releases with no API breakage.
#
# Do NOT drop the [standard] extra from uvicorn — it provides `websockets`,
# which notification-service needs to serve the STOMP broker at /ws.
#
# Python floor is 3.11 (verified on 3.11.9: all 119 backend tests pass and all
# ten services boot). Render resolves its own interpreter, so the blueprint
# should pin PYTHON_VERSION there rather than relying on this floor.
#
# The shared `cybercommon` package is installed separately from ./services/common
# (see render.yaml buildCommand), because pip cannot resolve a local path
# dependency from inside a requirements.txt reliably across platforms.
# ────────────────────────────────────────────────────────────────────────────
